# Читай — навчальна бібліотека

Flask-проєкт для ЛР03 з основ програмної інженерії. Цвіркунов Олексій Дмитрович, ІПЗ-21.

Чотири адаптивні сторінки про українську літературу: головна, про нас, каталог і контакти. Індивідуальне виконання; командні внески не імітуються.

## Запуск у Windows

Потрібен Python 3.12 або новіший. Відкрийте PowerShell у папці проєкту:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Відкрийте [http://127.0.0.1:5000](http://127.0.0.1:5000). Зупинка сервера — `Ctrl+C`.

Якщо активація середовища недоступна, можна запускати його інтерпретатор напряму:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Після створення `.venv` і встановлення залежностей працює також `Запустити.bat`.

## Запуск у macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

## Сторінки

| Адреса | Зміст |
|---|---|
| `/` | Головна та три книжки для знайомства |
| `/about` | Про бібліотеку та її навчальне призначення |
| `/catalog` | Добірка із шести творів |
| `/contacts` | Автор, група та посилання на GitHub |

Невідомі адреси повертають оформлену сторінку зі статусом 404. Каталог статичний: бази даних, реєстрації та видачі книжок у цій лабораторній немає.

## Структура

- `app.py` — маршрути Flask і навчальна добірка.
- `templates/base.html` — спільний каркас сторінок і меню.
- `templates/` — дочірні шаблони та макрос картки книжки.
- `static/css/style.css` — локальні стилі й медіазапити.
- `static/js/menu.js` — відкриття, закриття та стан мобільного меню.
- `tests/test_app.py` — 8 автоматичних перевірок.
- `lab-reports/` — звіт і 8 справжніх скріншотів сторінок.

Для перевірки з активованим середовищем:

```console
python -m unittest discover -s tests -v
```
